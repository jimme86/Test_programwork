# Offgrid Lifestyle — Brand Kit v1

Starting brand assets for the four channels, plus the copy to pair with
them. Treat this as a first draft to react to, not a final brand — swap in
a designer-made mark later if you want one.

**Live, exportable brand kit:** https://claude.ai/code/artifact/e43fafbf-676a-497f-b15d-2587e2462eb8

Open it and use **Export → PNG** on each artboard to download:

| Artboard | Size | Use it for |
|---|---|---|
| Profile picture | 1080×1080 | Instagram profile photo, Facebook Page profile photo, TikTok profile photo (same square works on all three) |
| Facebook cover photo | 820×312 | Facebook Page cover image |
| YouTube banner | 2560×1440 (safe zone 1546×423, centered) | YouTube channel art |

## Concept

- **Mark**: a sunrise over two mountain peaks with a ground line — reads as
  "off-grid," "sunrise/solar," and "outdoors" at once, and still reads at
  small (profile-picture) sizes as a simple silhouette.
- **Palette**: deep forest green background (`#17251C`), warm cream mark
  (`#F4EEDD`), clay/terracotta accent (`#C1622D`, `#8C4620`).
- **Type**: Space Grotesk (display/wordmark) + Work Sans (body/bio text).
