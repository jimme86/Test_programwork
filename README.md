## Offgrid Lifestyle · Social + Shopify integration

This repo contains the plugin and setup materials for connecting the
**offgrid-lifestyle.com** Shopify store to Instagram, Facebook, TikTok, and
YouTube.

- [`shopify-app/`](shopify-app/) — the Shopify plugin itself (Remix +
  Polaris embedded admin app): OAuth connections, product catalog sync,
  new-product auto-posting, and a storefront social feed embed. Start with
  [`shopify-app/README.md`](shopify-app/README.md).
- [`docs/SOCIAL_CHANNEL_SETUP.md`](docs/SOCIAL_CHANNEL_SETUP.md) — the
  step-by-step checklist for creating the four social accounts and their
  developer API credentials (this part has to be done by a human as the
  business owner — it can't be automated).
- [`docs/BRAND_ASSETS.md`](docs/BRAND_ASSETS.md) — starter brand kit
  (profile picture, Facebook cover, YouTube banner, bios) and a link to the
  exportable design artifact.
- [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md) — how to host and install the
  plugin on the live store.
